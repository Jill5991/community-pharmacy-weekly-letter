# 社區藥局每週情報 — 2026-W17

> 生成日期：2026-04-25
> 核心合作科別：家醫 / 內分泌 / 腸胃 / 心臟 / 神經 / 婦產 / 牙科
> 涵蓋期間：2026-04-18 至 2026-04-25
> 來源：OpenEvidence、FDA Drug Safety、Medscape、Pharmacy Times、Drug Topics、Annals、Diabetologia、Circulation、Europace、CPT

## 一、摘要

1. **AACE 2026 糖尿病治療演算法**再次強調以共病與器官保護導向選藥，對社區藥局最直接的影響是：不能只看 HbA1c，還要主動辨識 ASCVD、HF、CKD、肥胖與低血糖風險，並把 GLP-1 RA / SGLT2 inhibitor 的適應情境講清楚。
2. **偽冒 GLP-1 網路藥局**已成即時藥安議題。Drug Topics 提到約一成線上藥局網站遭複製用於販售假 GLP-1 產品；對社區藥局而言，這週最實際的工作是主動做來源查核與病人衛教。
3. **Tandem Mobi insulin pump correction**屬於需立即辨識的器材安全訊號。若病人回報馬達異常警示、停藥或血糖突然失控，社區藥局要先想到裝置問題，而不只懷疑胰島素失效或使用依從性。
4. **婦女健康與神經用藥的交叉風險**本週特別值得前台攔截，包括 menopause hormone therapy 與 CYP3A4 inducer、以及 topiramate 與避孕失敗 / 致畸風險。
5. **OpenEvidence 本週分級**認為：AACE diabetes guidance 與 counterfeit GLP-1 safety alert 屬 `practice-changing now`；Tandem Mobi correction、CMS prior authorization 改革與 menopause HT 相關衛教屬 `operationally important`；orforglipron、updated GMI、exercise snacks、CYP1A2 nomenclature 則偏向 `watchlist only`。

## 二、家醫 / 基層照護

### 本週更新

- Drug Topics / Pharmacy Times 持續聚焦 **Updated AACE Algorithms Guide Type 2 Diabetes Management**，核心訊息是把體重、心腎保護、低血糖風險與共病納入第一線選藥，而不是只做「降糖藥輪替」。
- Drug Topics 提到 **CMS 擬加速且透明化 prior authorization** 流程，短期內雖未直接改變台灣健保流程，但反映國際趨勢已從「事後拒付」轉向「前端透明」。
- Pharmacy Times 討論 **persistent drug shortages** 與用藥錯誤攔截點，對社區藥局而言比單一新藥消息更接近日常工作。

### 對社區藥局的意義

- 家醫科病人常在社區端同時帶有糖尿病、高血壓、肥胖、骨關節痛與多重慢箋。這週重點不是新增哪一顆藥，而是重新整理慢性病用藥優先順序與追蹤語言。
- 若病人詢問「為何醫師改成 GLP-1 / SGLT2 而不是再加一顆傳統降糖藥」，藥師可用「除了血糖，也在處理體重、心臟、腎臟風險」來做一致說明。

### 建議行動 / 轉介 / 監測 / 衛教

- 針對 T2D 病人，主動在調劑時加一句：是否已有心衰竭、冠心病、腎功能下降、體重困擾或反覆低血糖。
- 遇到缺藥或換廠牌時，更新病人的實際服法與剩藥天數，避免重複領藥或自行補買網路來源產品。
- 若病人使用多種 OTC 止痛、感冒藥或保健品，優先檢查重複成分與可能交互作用，而非只核對處方藥。

## 三、新陳代謝科

### 本週更新

- Pharmacy Times 報導 **orforglipron 在 Phase 3 ACHIEVE-4** 顯示持續降糖與減重效果；同批次媒體也提到其心血管獲益訊號。現階段仍屬 watchlist，尚未改變社區端實務。
- Diabetologia 刊出 **updated glucose management indicator (GMI)**，指出新版 GMI 與 HbA1c 的對齊度優於現行算法。
- Diabetologia 另一篇隨機 crossover 研究顯示 **exercise snacks** 可降低 T2D 病人的餐後高血糖與血糖波動。
- FDA 發布 **Tandem Mobi insulin pump correction**，為本週最需要即時處理的糖尿病安全議題。

### 對社區藥局的意義

- 目前最該做的不是先炒熱 orforglipron，而是把病人的 GLP-1 / insulin 真實用法、來源與裝置問題先顧好。
- updated GMI 提醒我們：CGM 報告上的數字不應直接取代 HbA1c 解讀，若兩者不一致，需提醒病人回診由醫師整體判讀。
- exercise snacks 是很適合社區端衛教的生活型態介入，特別適用於飯後久坐、活動量低的 T2D 病人。

### 建議行動 / 轉介 / 監測 / 衛教

- 使用 insulin pump 的病人若出現異常警示、頻繁高血糖或未明原因停機，先確認是否涉及 Tandem Mobi correction，必要時請病人立即聯繫原開立團隊與廠商。
- 向使用 CGM 的病人說明：GMI 是參考值，若與 HbA1c 差異明顯，不要自行更改藥量。
- 對願意配合生活型態調整的病人，可建議從「每餐後 2 至 5 分鐘輕量活動」開始，比抽象地說「多運動」更容易落地。

## 四、腸胃科

### 本週更新

- 本週腸胃科直接可轉為社區行動的高強度訊號不多；現有 candidate pool 以一般 PPI / H. pylori / IBD 關鍵字為主，但沒有比上週更改變行為的新規範或警訊。
- 另一方面，GLP-1 類藥物與胃排空延遲仍持續影響腸胃不適、服藥時序與口服藥吸收解釋，這在社區端比專科新聞更常見。

### 對社區藥局的意義

- 這週腸胃科重點偏向「把已知問題做得更扎實」：PPI 長期使用適應症複核、慢性便祕與腹脹衛教、GLP-1 常見腸胃副作用分流。

### 建議行動 / 轉介 / 監測 / 衛教

- 若病人新近開始 GLP-1 類藥物並抱怨噁心、早飽、便祕，先確認劑量遞增速度、飲食型態與脫水風險，再決定是否建議回診。
- 長期使用 PPI 超過 8 至 12 週且無明確適應症者，可提醒病人與醫師討論是否需要降階或間歇使用。
- `_本週無明確新增、足以改變腸胃科處方趨勢的新訊號_`

## 五、心臟內科

### 本週更新

- Medscape 彙整 **Heart Failure Updates From ACC 2026**，雖然屬於 watchlist 性質，但再次強化 HF 治療已是「四大支柱」常態化管理。
- Circulation 本週有心血管相關文獻進站，但沒有比現有 HF / ASCVD 實務更立即改變社區端處置的新藥安訊號。
- 由於 AACE 2026 diabetes algorithm 再次強調心腎保護，心臟內科與內分泌用藥的交界變得更重要。

### 對社區藥局的意義

- 社區藥局應把 SGLT2 inhibitor 視為心衰竭藥，而不只是糖尿病藥。
- 若病人只記得「利尿劑、降壓藥」，藥師可以幫忙重新標示每顆藥的角色，提升依從性與對副作用的辨識能力。

### 建議行動 / 轉介 / 監測 / 衛教

- 對 HF 病人調劑時，主動問：最近是否體重上升、下肢水腫、夜間喘、血壓過低或頭暈。
- 若同時有 diabetes + ASCVD / HF，提醒病人 SGLT2 inhibitor 的效益不只在血糖，並衛教脫水、泌尿生殖道感染與 sick day rule。
- 若病人同時領到 NSAID、利尿劑、RAAS blocker，留意腎功能惡化與體液狀態。

## 六、神經內科

### 本週更新

- Annals 發表 **Core Performance Measures for Migraine Headache: A Review by the American College of Physicians**，屬於偏實務流程導向的訊號。
- Medscape 報導 **High-Dose Flu Vaccine Linked to Lower Dementia Risk**，現階段偏觀察性支持訊號，適合列 watchlist，不宜直接當作 dementia 預防治療承諾。
- CPT 發表 **PharmVar GeneFocus: CYP1A2**，更新 nomenclature 與臨床意涵，對 clozapine、theophylline、tizanidine 等用藥辨識有幫助。

### 對社區藥局的意義

- migraine 本週真正可落地的重點不是新藥，而是把過度使用止痛藥、預防性治療適應症、與女性生育風險一起抓出來。
- CYP1A2 更新提醒藥師：吸菸、停菸、感染、藥物抑制 / 誘導與基因差異會共同影響濃度，不可只看處方劑量。

### 建議行動 / 轉介 / 監測 / 衛教

- 對常買止痛藥的 headache 病人，主動問每月使用頻率，避免 medication-overuse headache。
- 女性病人若使用 topiramate、valproate 等藥物，應同步確認避孕與懷孕計畫。
- 使用 clozapine、theophylline 或 tizanidine 的病人，如近期開始 fluvoxamine、停菸或出現感染，要提高濃度上升警覺。

## 七、婦產科

### 本週更新

- Medscape 本週焦點之一是 **HT: A Proactive Approach to Menopause Management**，另有 **Progesterone Recommended for Perimenopause** 類訊號，整體方向是更積極但也更分層地處理更年期症狀。
- CPT 白皮書 **Advancing Long-Acting Therapeutics for Maternal and Pediatric Health** 提醒孕期、哺乳與兒科長效製劑的研發與給藥便利性是未來方向，但現階段仍屬 watchlist。
- OpenEvidence 特別點出：更年期 hormone therapy 的社區端價值，在於提早辨識交互作用、禁忌症與衛教落差，而不是替代婦產科做處方決策。

### 對社區藥局的意義

- 社區藥局常是病人第一次詢問「熱潮紅要不要用荷爾蒙」的地方。這週重點是把風險盤點做完整：子宮是否仍在、VTE / stroke 風險、乳癌病史、抽菸、偏頭痛、以及併用藥。
- 若病人同時使用抗癲癇藥、草藥或精神科藥物，交互作用可能使荷爾蒙效果下降或副作用上升。

### 建議行動 / 轉介 / 監測 / 衛教

- 衛教時固定用三句話整理：`Pregnancy` 是否可用、`Lactation` 是否相容、`Contraception` 是否需要額外避孕。
- 若病人使用 systemic estrogen 且仍有子宮，注意是否合併 progesterone 保護子宮內膜。
- 若同時使用 carbamazepine、phenobarbital、phenytoin 或 St John's wort，提醒病人 hormone therapy / OCP 可能失效，應回原醫師評估。

## 八、牙科

### 本週更新

- 本週沒有牙科專屬、足以改變社區藥局行為的新文獻或新警訊。
- 但偽冒 GLP-1 網路藥局與一般用藥錯誤議題，仍會間接影響牙科病人的術前用藥確認與慢病控制評估。

### 對社區藥局的意義

- 牙科病人常在社區端臨時補買止痛藥、抗生素或口腔潰瘍產品。這週更重要的是把高風險慢病與處置前用藥史問清楚。

### 建議行動 / 轉介 / 監測 / 衛教

- 若病人近期有拔牙、植牙或侵入性處置，補發 NSAID / 抗生素時留意其 anticoagulant、antiplatelet、糖尿病控制與腎功能狀態。
- 對 bisphosphonate、denosumab 或長期類固醇病人，若有侵入性牙科處置安排，可提醒主動告知牙醫師完整用藥史。
- `_本週無新訊號_`

## 九、藥物安全警訊

### 1. Tandem Mobi insulin pump correction

- 來源：FDA Drug Safety，2026-04-22
- 重點：裝置可能出現錯誤馬達問題偵測，導致警示、停機或影響胰島素輸送。
- 社區藥局處置：
  - 若病人回報不明高血糖、泵浦異常警示或近期更換耗材後持續失控，先問是否為 Tandem Mobi。
  - 不要只建議「多補打一點 insulin」；應先確認裝置安全性與是否需回原團隊處理。

### 2. Counterfeit GLP-1 online pharmacy risk

- 來源：Drug Topics
- 重點：約一成線上藥局網站被複製用於販售假 GLP-1 產品，屬即時病人安全風險。
- 社區藥局處置：
  - 主動提醒病人不要從不明社群連結、仿冒網站或來路不明代購購買 GLP-1。
  - 若病人拿來路不明筆針、預填筆或冷藏製品來詢問使用方式，應先查核來源，不應直接教學。

### 3. Drug shortages 與 medication error 攔截

- 來源：Pharmacy Times
- 重點：缺藥環境下最容易出現替代藥轉換錯誤、重複給藥、濃度 / 劑型混淆。
- 社區藥局處置：
  - 缺藥換藥時固定核對：成分、strength、頻次、適應症、剩藥與舊藥是否停用。

## 十一、本週 Takeaways

1. 這週最值得立即改變行為的不是新藥上市，而是 **AACE diabetes guidance + 偽冒 GLP-1 safety alert + Tandem Mobi correction** 三件事。
2. 社區藥局在 diabetes 照護上要從「補藥窗口」升級成「共病風險翻譯者」；病人真正需要的是把 GLP-1、SGLT2、insulin、CGM 與生活型態建議串成同一套語言。
3. 婦女健康與神經用藥的交界是本週最容易漏掉的風險點，尤其是 topiramate、enzyme inducer、HRT / OCP 與懷孕計畫。
4. GMI、exercise snacks、orforglipron、CYP1A2 nomenclature 都值得追，但目前仍應放在教育與 watchlist，而不是過度承諾療效或替病人自行改藥。
5. 沒有牙科大新聞的一週，反而更適合把術前用藥核對、慢病控制與止痛藥安全使用做紮實。

## 十二、OpenEvidence 點評

- OpenEvidence 本週最明確的判讀是：**真正需要現在就改變社區藥局行為的，只有少數幾項，而且都偏向安全與流程，而非炫目的新藥 headline。**
- `Practice-changing now`：
  - AACE 2026 diabetes algorithm：藥師應把共病與器官保護納入衛教與藥歷盤點。
  - Counterfeit GLP-1 alert：需立即強化來源辨識與病人教育。
- `Operationally important`：
  - Tandem Mobi correction：調劑端須學會辨識裝置故障線索。
  - Menopause HT counseling：前台要攔下交互作用與生育相關風險。
  - CMS prior authorization reform：提示未來慢病用藥流程將更重視透明與文件化。
- `Watchlist only`：
  - Orforglipron、updated GMI、exercise snacks、CYP1A2 nomenclature、high-dose flu vaccine 與 dementia 風險關聯。
- 總結一句話：**本週社區藥局最重要的價值，不是比醫師更早知道新藥，而是比任何人更早發現病人手上的藥、裝置、來源與生活型態哪裡開始出錯。**
